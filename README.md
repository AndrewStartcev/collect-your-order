# Собери заказ!

Однодневная web-first мини-игра про сбор заказов в магазине/на складе.

## Цель проекта

Сделать компактную игру на 1–2 часа прохождения и использовать её как эталонный production-проект для нового протокола разработки HTML5-игр.

## Стек

- Phaser 4
- Vite
- TypeScript
- Pixel art
- Web-first: Пикабу / VK / OK, затем Яндекс при необходимости

## Core loop

Получить заказ → найти и выбрать товары → при необходимости выбрать замену → отправить заказ → получить деньги / отзыв / штраф → повысить рейтинг → приблизиться к званию «Сборщик №1».

Подробности: `docs/GAME_BRIEF.md`.
