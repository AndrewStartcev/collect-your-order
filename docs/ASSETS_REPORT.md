# Batch 01 — графика для проверки стиля

## Состав поставки

Только Batch 01 из `ASSET_MANIFEST.md`: 3 элемента окружения, 3 спрайта персонажа/тележки, 9 элементов UI и 12 товаров. Production-файлы находятся в `assets/environment`, `assets/character`, `assets/ui`, `assets/products`.

`preview-batch-01.png` в корне проекта — сборочная композиция 1600×900 по `WIREFRAME.md`. `assets/contact-sheet-batch-01.png` — обзор отдельных элементов. Это материалы проверки, их не нужно нарезать для игры.

## Использование

- Координаты левой панели: (24,126), размер 350×750. Внутренняя безопасная область: x=24..326, y=100..690 относительно ассета; верх занят зажимом.
- Телефон: (1216,126), размер 360×750. Безопасная область контента: x=30..328, y=70..690 относительно ассета.
- Панели содержат пустой navy-фон. Все надписи, числа, отзывы, строки заказа и прогресс должны выводиться игрой поверх PNG.
- Кнопки — одинаковый canvas 300×72, текст размещается отдельно по центру. Три состояния поставляются отдельными файлами.
- Товар — canvas 64×64, центрирование по видимому силуэту, максимальная сторона 52–58 px. Не увеличивать разные товары по отдельным произвольным коэффициентам.
- Worker idle/pick — canvas 96×128. Тележка 160×128 поставляется пустой; товары в ней можно размещать отдельными иконками.
- Стеллаж 224×448 содержит четыре пустых уровня. В preview пять модулей размещены в зоне x=420..1170, y=190..680 с демонстрационным масштабированием. Production-интеграция должна сохранить сетку и hit areas утверждённого prototype.
- Рекомендуется nearest-neighbor для масштабирования растров; прозрачный alpha сохраняется. Фон пола является сплошной текстурой.

## Производство и воспроизводимость

Графика создана встроенным ImageGen, отдельным запросом на каждый ассет/состояние. Запросы и параметры экспорта перечислены в `assets/batch-01-manifest.json`. Крупные генерации остаются вне Git; в репозитории только финальные PNG.

`tools/art/normalize.py` приводит размер PNG к манифесту и исключает практически невидимый alpha-мусор из границ спрайтов. `tools/art/build-preview.py` собирает обзор из настоящих production-файлов. Подписи, простые подложки и значения в preview — демонстрационные элементы программного UI, не дополнительные production-ассеты.

`tools/art/verify.py` проверяет комплектность, размеры, формат RGBA, поля товаров, стык пола и размер preview. Результаты записываются в `assets/batch-01-qa.json`.

Финальный технический контроль: **27/27 PASS**. После генерации выполнена нормализация размеров; для кнопок и таблички удалены внешние пустые поля и установлен общий отступ 3 px. Пол экспортирован как отражённый повтор исходной непрозрачной текстуры: крайние столбцы совпадают побитно. Такой технический экспорт не требует дорисовки при интеграции.
