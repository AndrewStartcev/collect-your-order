# SCOPE — однодневная v1

## Цель

Не делать «маленькую большую игру». Сделать один очень хорошо работающий основной экран и достаточный объём data-driven контента, чтобы прохождение занимало около 1–2 часов.

## Входит в v1

### Gameplay

- 1 основной gameplay-screen;
- click/tap по товарам;
- текущая корзина;
- отправка заказа;
- правильные, лишние и пропущенные товары;
- количество одной позиции;
- отсутствующий товар;
- система замен;
- таймер;
- расчёт результата заказа;
- рейтинг;
- деньги;
- штрафы/чаевые;
- отзывы;
- карьерный прогресс.

### Контент

Целевые значения, допускается уменьшение при нехватке времени:

- 36–48 товаров;
- 6 товарных категорий;
- 6 рангов;
- 30+ шаблонов отзывов;
- 5 типов результата заказа;
- процедурная генерация заказов;
- постепенное повышение сложности;
- 4 простых улучшения;
- бесконечный режим после основной карьеры — только если основной цикл готов и отполирован.

### UX

- мышь;
- touch;
- landscape desktop/tablet first;
- responsive fit для небольших экранов;
- короткий onboarding через первый заказ, без отдельной длинной инструкции;
- пауза/звук;
- локальное сохранение прогресса.

### Polish

Минимальный обязательный набор:

- hover/press feedback;
- товар визуально перемещается в корзину;
- feedback правильного/неправильного действия;
- появление результата заказа;
- анимация денег/рейтинга;
- небольшие particles;
- screen/UI punch только там, где уместно;
- SFX для выбора, сканирования, отправки и результата;
- короткий музыкальный loop, если успеваем без ущерба core gameplay.

## Не входит в v1

- свободное управление персонажем;
- физическая ходьба между рядами;
- полноценная карта магазина;
- NPC-покупатели;
- диалоговая система;
- сюжетная кампания;
- несколько магазинов/локаций;
- сложная экономика;
- реальные бренды продуктов;
- multiplayer;
- backend;
- платёжная система;
- сложные ежедневные задания;
- десятки экранов меню;
- 3D;
- React.

## Правило scope

Если новая идея требует отдельной большой системы, нового экрана, заметного количества уникальной графики или более ~60–90 минут разработки, она переносится после v1, если не является критической для core loop.

## Приоритет при нехватке времени

1. Играбельность.
2. Понятность UX.
3. Результат заказа и отзывы.
4. Карьерный прогресс.
5. Pixel-art интеграция.
6. Juice/polish.
7. Дополнительный контент.
8. Дополнительные режимы.
